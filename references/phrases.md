# Phrasen zum Streichen

Diese Phrasen, Einleitungen und Füllwörter sind die häufigsten Verräter von KI-generiertem Deutsch. Streiche sie ersatzlos oder ersetze sie durch präzise Sprache.

---

## 1. Räusper-Einstiege (Throat-Clearing)

Floskeln, mit denen die KI Anlauf nimmt, anstatt direkt den Gedanken auszusprechen:

- „Hier ist das Ding:“
- „Fakt ist:“ / „Tatsache ist:“
- „Die Wahrheit ist:“
- „Klar ist:“ / „Machen wir uns nichts vor:“
- „Lass uns ehrlich sein:“ / „Hand aufs Herz:“
- „Hier ist der Haken:“ / „Das Problem ist jedoch:“
- „Es stellt sich heraus, dass…“
- „Es ist wichtig zu beachten, dass…“
- „Es gilt zu bedenken, dass…“
- „Es lohnt sich, einen Blick auf [X] zu werfen.“
- „In der heutigen, schnelllebigen Welt…“
- „In einer Zeit, in der [X] immer wichtiger wird…“
- „Im Zeitalter der Digitalisierung / von KI…“
- „Zusammenfassend lässt sich sagen, dass…“
- „Alles in allem…“
- „Um es auf den Punkt zu bringen:“

**Lösung:** Streiche den gesamten Einleitungssatz. Beginne direkt mit der Kernaussage.

---

## 2. Schein-Bedeutung & Dramatik-Krücken (Emphasis Crutches)

Künstliche Verstärker, die dem Text falsche Tiefe verleihen sollen:

- „Punkt.“ / „Basta.“
- „Lass das mal kurz sacken.“ / „Lass das wirken.“
- „Und das ist auch gut so.“ / „Und das ist völlig in Ordnung.“
- „Aus gutem Grund.“
- „Das ist entscheidend, weil…“
- „Hier kommt der eigentliche Clou:“
- „Ein echter Gamechanger.“
- „Versteh mich nicht falsch.“

---

## 3. KI-Business-Jargon & Phrasen

Viele englische KI-Ausdrücke werden von Modellen hölzern ins Deutsche übersetzt oder unreflektiert eingesetzt. Ersetze sie durch klare, unprätentiöse Begriffe:

| Unbedingt meiden | Bessere Alternative |
|------------------|----------------------|
| **eintauchen in** (z. B. „Lass uns eintauchen“) | untersuchen, analysieren, betrachten, ansehen |
| **navigieren** (z. B. „Herausforderungen navigieren“) | lösen, bewältigen, meistern, umgehen mit |
| **aufgreifen / annehmen** (lean into) | akzeptieren, sich konzentrieren auf |
| **Landschaft** (im Sinne von „die Markt-Landschaft“) | Markt, Branche, Umfeld, Lage |
| **Gamechanger** | spürbarer Vorteil, wichtiger Fortschritt |
| **ganzheitlich / holistisch** | umfassend, vollständig |
| **maßgeschneidert** | passend, individuell, abgestimmt |
| **facettenreich** | vielseitig, unterschiedlich |
| **spielt eine zentrale/entscheidende Rolle** | ist wichtig, entscheidet über |
| **stellt einen wichtigen Meilenstein dar** | ist ein Meilenstein |
| **Synergien heben / nutzen** | zusammenarbeiten, kombinieren |
| **auf das nächste Level heben** | verbessern, steigern, ausbauen |
| **Mehrwert bieten** | nützen, helfen, Zeit/Geld sparen |
| **am Ende des Tages** | letztlich, unterm Strich, im Ergebnis |
| **nachhaltig beeinflussen** | prägen, verändern |
| **Ökosystem** (wenn kein Bio-System gemeint ist) | Plattform, Produktwelt, Umfeld |

## 4. Füllwörter und Weichspüler-Adverbien

Adverbien schwächen Sätze fast immer. Streiche sie konsequent:

- wirklich
- einfach
- buchstäblich
- tatsächlich
- ehrlich gesagt
- im Grunde / grundsätzlich
- letztlich / letztendlich
- im Wesentlichen
- quasi / sozusagen
- zweifelsohne / zweifellos
- unweigerlich
- interessanterweise
- bemerkenswerterweise
- erfreulicherweise / bedauerlicherweise
- essenziell / unabdingbar
- signifikant (sofern keine statistische Signifikanz gemeint ist)

---

## 5. Meta-Kommentare und Regieanweisungen

Texte sollten sich selbst erklären und nicht ihre eigene Struktur ankündigen:

- „Spoiler:“ / „Plot-Twist:“
- „Du ahnst es schon, aber…“
- „Dazu kommen wir gleich noch.“
- „Aber das würde den Rahmen dieses Artikels sprengen.“
- „Das ist ein Thema für einen eigenen Beitrag.“
- „Wie wir im Folgenden sehen werden…“
- „Lass mich dir erklären, warum…“
- „In diesem Abschnitt werfen wir einen Blick auf…“
- „Ich möchte an dieser Stelle betonen…“

---

## 6. Vage Pseudo-Aussagen

Sätze, die Bedeutung vortäuschen, ohne konkrete Information zu liefern:

- „Die Gründe dafür sind vielfältig und komplex.“
- „Die Auswirkungen sind weitreichend.“
- „Die Herausforderungen sind real.“
- „Hier steht viel auf dem Spiel.“
- „Die Implikationen für die Branche sind enorm.“

**Lösung:** Wenn etwas wichtig, komplex oder folgenreich ist: Nenne die exakte Zahl, das konkrete Problem oder die unmittelbare Folge.
