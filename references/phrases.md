# Phrasen zum Streichen

Diese Phrasen, Einleitungen, Metaphern und Füllwörter sind die häufigsten Verräter von KI-generiertem Deutsch. Streiche sie ersatzlos oder ersetze sie durch präzise Sprache.

---

## 1. Räusper-Einstiege (Throat-Clearing)

Floskeln, mit denen die KI reflexartig Anlauf nimmt, anstatt direkt den Gedanken auszusprechen:

### Die zeitlichen & epischen Floskeln
- „In der heutigen, schnelllebigen / digitalen / vernetzten Welt…“
- „In einer Zeit, in der [X] immer wichtiger wird…“
- „Im Zeitalter der Digitalisierung / von Künstlicher Intelligenz…“
- „In einer sich ständig verändernden Landschaft…“
- „Seit jeher haben Menschen…“

### Die Ankündigungs- und Scheinbedeutungs-Floskeln
- „Fakt ist:“ / „Tatsache ist:“
- „Die Wahrheit ist:“
- „Klar ist:“ / „Machen wir uns nichts vor:“
- „Hier ist der Haken:“ / „Das Problem ist jedoch:“
- „Es ist wichtig zu beachten / betonen / erwähnen, dass…“
- „Es gilt zu bedenken, dass…“
- „Es lohnt sich, einen genaueren Blick auf [X] zu werfen.“
- „Es stellt sich heraus, dass…“
- „Es steht außer Frage, dass…“
- „Es liegt auf der Hand, dass…“
- „Um die Bedeutung von [X] zu verstehen, muss man zunächst…“
- „Hier ist das Ding:“ (Hölzerner Anglizismus für *„Here's the thing“*)

### Die Pseudo-Einladungen
- „Tauchen wir ein in die faszinierende Welt von…“
- „Lassen Sie uns gemeinsam einen Blick darauf werfen…“
- „Lass uns ehrlich sein:“ / „Hand aufs Herz:“

**Regel:** Streiche den gesamten Einleitungssatz. Beginne deinen ersten Satz sofort mit dem handelnden Subjekt oder der Kernaussage.

## 2. KI-Schmuckwörter & pathetische Metaphern (Purple Prose)

Große Sprachmodelle greifen überproportional oft zu geschwollenen Bildern und pseudointellektuellen Schmuckwörtern, um gewöhnliche Sachverhalte künstlich aufzuwerten:

| KI-Schmuckwort | Warum es Slop ist | Bessere Alternative |
|----------------|-------------------|----------------------|
| **das Herzstück** | Die inflationärste KI-Metapher für jedes Kernfeature. | der Kern, die Hauptfunktion, das Fundament, der wichtigste Teil |
| **der Wandteppich** | Absurde 1:1-Übersetzung des englischen *„tapestry“* (*„ein bunter Wandteppich an Möglichkeiten“*). | Vielfalt, Mischung, Spektrum, Facetten |
| **der Katalysator** | Chemische Metapher für jede noch so banale Beschleunigung. | Auslöser, Antrieb, Beschleuniger, Anstoß |
| **der Paradigmenwechsel** | Jede kleine Neuerung wird zur weltgeschichtlichen Wende aufgeblasen. | Neuausrichtung, Kehrtwende, Wandel, Umdenken |
| **der Wegbereiter / Vorreiter** | Abgedroschene Heroisierung von Tools oder Firmen. | Pionier, erstes Produkt, Vorbild (oder weglassen) |
| **der Leuchtturm / Leuchtturmprojekt** | Ausgenudelter PR-Begriff für Vorzeigeprojekte. | Musterbeispiel, Referenzprojekt, Vorbild |
| **die Symbiose / perfekte Symbiose** | Wird reflexartig für jede funktionierende Zusammenarbeit genutzt. | Kombination, Zusammenspiel, Teamarbeit |
| **der Dreh- und Angelpunkt** | Sprachliche Schablone für wichtige Dinge. | das Wichtigste, der Hauptgrund, das Zentrum |
| **die Reise** (*„agile Reise“*, *„transformative Reise“*) | Niemand reist, wenn Software umgestellt wird. | Entwicklung, Umstellung, Einführung, Prozess |
| **den Grundstein legen / Fundament bilden** | Baugewerbe-Metaphorik für schlichte Vorbereitung. | die Basis schaffen, vorbereiten, starten |
| **Potenziale heben / entfalten** | Hohlste Berater-Lyrik. | besser nutzen, ausbauen, steigern |

## 3. KI-Business-Jargon & Lehnübersetzungen

Viele englische KI-Begriffe werden unreflektiert oder hölzern ins Deutsche übersetzt. Ersetze sie durch klare, unprätentiöse deutsche Begriffe:

| Unbedingt meiden | Bessere Alternative |
|------------------|----------------------|
| **eintauchen in** (z. B. *„Lass uns eintauchen“*) | untersuchen, analysieren, betrachten, ansehen |
| **navigieren** (z. B. *„Herausforderungen navigieren“*) | lösen, bewältigen, meistern, umgehen mit |
| **Landschaft** (z. B. *„Marktlandschaft“*, *„Tool-Landschaft“*) | Markt, Branche, Angebot, Palette, Lage |
| **nahtlos** (z. B. *„nahtlos integrieren“*, *„nahtloser Übergang“*) | direkt, reibungslos, automatisch, ohne Bruch |
| **maßgeschneidert** | passend, individuell, abgestimmt, gezielt |
| **ganzheitlich / holistisch** | umfassend, vollständig, durchgängig |
| **facettenreich / vielschichtig** | vielseitig, unterschiedlich, komplex |
| **robust** (z. B. *„eine robuste Strategie/Lösung“*) | stabil, sicher, zuverlässig, solide |
| **spielt eine zentrale/entscheidende Rolle** | ist wichtig, entscheidet über, beeinflusst |
| **stellt einen wichtigen Meilenstein dar** | ist ein Meilenstein, bringt uns voran |
| **Synergien heben / nutzen** | zusammenarbeiten, kombinieren, bündeln |
| **auf das nächste Level heben / bringen** | verbessern, steigern, ausbauen, modernisieren |
| **Mehrwert bieten / schaffen** | nützen, helfen, Zeit/Geld sparen, Nutzen stiften |
| **am Ende des Tages** | letztlich, unterm Strich, im Ergebnis |
| **nachhaltig beeinflussen** (wenn nicht ökologisch) | dauerhaft prägen, langfristig verändern |
| **Ökosystem** (wenn keine Biologie gemeint ist) | Plattform, Produktwelt, Umfeld, Netzwerk |
| **Gamechanger / bahnbrechend / revolutionär** | spürbarer Vorteil, echter Fortschritt (oft ganz streichen) |
| **lean into / annehmen / aufgreifen** | sich konzentrieren auf, akzeptieren, nutzen |

## 4. Scharnier-Floskeln & Schulaufsatz-Übergänge

Deutsche KI-Texte ersticken in steifen Scharnierwörtern, um Absätze mechanisch aneinanderzuketten. Menschliche Sprache fließt durch inhaltliche Logik, nicht durch Formel-Verbinder:

- „Darüber hinaus…“
- „Des Weiteren…“
- „Ferner…“
- „Zusätzlich sei erwähnt, dass…“
- „In diesem Zusammenhang ist festzuhalten…“
- „Hierbei darf nicht außer Acht gelassen werden, dass…“
- „Nicht zuletzt…“
- „Nichtsdestotrotz…“
- „Ein weiterer wichtiger Aspekt / Faktor ist…“
- „Mit diesem Gedanken im Hinterkopf…“
- „Es lässt sich argumentieren, dass…“

**Regel:** Streiche diese Bindeglieder fast ausnahmslos. Wenn zwei Sätze logisch aufeinander folgen, braucht es kein formales Warnsignal am Satzanfang.

---

## 5. Schein-Bedeutung & Dramatik-Krücken (Emphasis Crutches)

Künstliche Verstärker und Ausrufe, die Bedeutung vortäuschen, wo Fakten fehlen:

- „Punkt.“ / „Basta.“
- „Lass das mal kurz sacken.“ / „Lass das wirken.“
- „Und das ist auch gut so.“ / „Und das ist völlig in Ordnung.“
- „Aus gutem Grund.“
- „Das ist entscheidend, weil…“
- „Hier kommt der eigentliche Clou:“
- „Versteh mich nicht falsch.“
- „Ein echter Gamechanger.“
- „Und weißt du was?“

---

## 6. Schluss-Floskeln & Kalenderspruch-Outros (Fazit-Slop)

KI neigt dazu, unter jeden Text einen feierlichen Abspann oder eine moralisierende Lebensweisheit zu setzen:

- „Zusammenfassend lässt sich sagen, dass…“
- „Abschließend bleibt festzuhalten / zu betonen…“
- „Alles in allem zeigt sich…“
- „Um es auf den Punkt zu bringen:“
- „Eines ist sicher: …“
- „Letztendlich zeigt sich: Nur wer [X] tut, wird in Zukunft erfolgreich sein.“
- „Der Schlüssel liegt darin, die richtige Balance zu finden…“
- „…ist kein Sprint, sondern ein Marathon.“
- „Die Zukunft wird zeigen, wie sich die Dinge entwickeln.“

**Regel:** Ein guter Text braucht keine Zusammenfassung von 20 Zeilen davor. Schließe mit einem konkreten Fakt, einer klaren Handlungsanweisung oder stoppe einfach nach dem letzten Gedanken.

---

## 7. Füllwörter und Weichspüler-Adverbien (Hedging)

Adverbien und Weichmacher schwächen jede Aussage und deuten fast immer auf KI-generierte Absicherungsrhetorik hin:

### Häufigste KI-Füllwörter
- wirklich
- einfach
- buchstäblich
- tatsächlich
- ehrlich gesagt
- im Grunde / grundsätzlich
- letztlich / letztendlich
- im Wesentlichen
- quasi / sozusagen
- zweifelsohne / zweifellos
- unweigerlich
- essenziell / unabdingbar
- signifikant (sofern keine mathematische Signifikanz gemeint ist)

### Feigheits-Adverbien & KI-Absicherung
- möglicherweise / eventuell
- gewissermaßen / in gewisser Hinsicht
- durchaus
- schlichtweg / schlicht und ergreifend
- bemerkenswerterweise / interessanterweise
- erfreulicherweise / bedauerlicherweise
- dürfte wohl kaum überraschen

---

## 8. Meta-Kommentare und Regieanweisungen

Texte sollten sich selbst erklären und nicht ihre eigene Dramaturgie oder Struktur ankündigen:

- „Spoiler:“ / „Plot-Twist:“
- „Du ahnst es schon, aber…“
- „Dazu kommen wir gleich noch.“
- „Aber das würde den Rahmen dieses Artikels sprengen.“
- „Das ist ein Thema für einen eigenen Beitrag.“
- „Wie wir im Folgenden sehen werden…“
- „Lass mich dir erklären, warum…“
- „In diesem Abschnitt werfen wir einen Blick auf…“
- „Ich möchte an dieser Stelle betonen…“

---

## 9. Vage Pseudo-Aussagen

Sätze, die Bedeutung vortäuschen, ohne konkrete Information zu liefern:

- „Die Gründe dafür sind vielfältig und komplex.“
- „Die Auswirkungen sind weitreichend.“
- „Die Herausforderungen sind real.“
- „Hier steht viel auf dem Spiel.“
- „Die Implikationen für die Branche sind enorm.“

**Lösung:** Wenn etwas wichtig, komplex oder folgenreich ist: Nenne die exakte Zahl, das konkrete Problem oder die unmittelbare Folge.

---

## 10. Chatbot-Artefakte (Assistant-Spillover)

Reste der KI-Konversationsrolle, die in redaktionellen Texten, Mails oder Blogposts nichts verloren haben:

- „Klar, hier ist…“ / „Gerne! Hier sind die…“
- „Ich hoffe, das hilft dir weiter!“
- „Lass mich wissen, falls du noch weitere Fragen hast.“
- „Wie versprochen findest du hier…“
- „Tauchen wir direkt ein!“
